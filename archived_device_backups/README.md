# Device Backups (Old Architecture)
This directory organizes the files, scripts, and documentation that run on each specific device based on the old LeadFlow architecture. NO code has been deleted from the root directory; this is purely an organizational backup for reference.

- **mac/**: Files running on the Mac as a background standby failover.
- **firestick/**: Files that ran on the Firestick (Gateway & Bots).
- **vivo/**: Files meant for the Vivo phone (Primary automation).
- **cloudflare/**: Workers mapped to Cloudflare.
